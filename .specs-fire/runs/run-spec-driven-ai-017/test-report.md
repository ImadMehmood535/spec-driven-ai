## The defect this suite existed to find

**The two projects could not talk to each other in a browser.** The API never enabled CORS: a
preflight `OPTIONS /auth/login` returned **404**, and no `Access-Control-Allow-Origin` header was
sent.

Nothing before this run could have caught it:

- every backend verification used server-side `curl`, which does not enforce CORS
- every frontend test used MSW, which intercepts before a real network request
- both projects were served and inspected separately, never exercised together in a browser

Login simply never completed. Fixed by enabling CORS in `main.ts` with an explicit, configurable
allow-list — not a wildcard, since this is an authenticated API and the legitimate front ends are
known. 7 tests cover the configuration, including one asserting a wildcard is never produced.

**This is a backend change made inside a frontend work item.** It was not scope creep: the work
item's first acceptance criterion is that the administrator can sign in, and that was impossible
until the fix.
