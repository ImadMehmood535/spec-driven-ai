### On the act warnings

My first diagnosis was that the shared render helper lacked a router — which was true, and worth
fixing on its own: the testing standards call for the helper to provide query client, theme
**and router**, and I had listed the router without implementing it. Components using
`useRouter` in `ui-auth` would have needed it.

But adding the router did not silence the warnings. The actual cause was `next/link` observing
visibility to decide when to prefetch, with no `IntersectionObserver` in jsdom. A stub that
never reports intersection fixed it.

Worth recording because the first fix was correct and insufficient — it would have been easy to
call it done when the warning count had not moved.
