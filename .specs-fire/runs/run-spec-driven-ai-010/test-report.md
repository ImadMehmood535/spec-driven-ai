## Default deny — the assertion that matters most

Two tests cover it. `PermissionsGuard` refuses a route declaring no permission **even for a
caller holding every permission**, and a scan asserts every route-bearing controller declares
either `@RequiresPermission` or `@Public()`. A route added without a decorator therefore fails
closed rather than becoming silently reachable by any authenticated caller.

A third test cross-checks every `@RequiresPermission` name against `seed-catalogue.cjs`: a name
the seed does not create would lock the administrator out of that route with no way to grant it
through the API.
